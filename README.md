# Predictive Sales Forecast Analysis

**Intern ID:** CITS8270

This project utilizes machine learning regression to predict retail sales based on advertising spend, store traffic, and holiday status.

## Project Structure
- `data/`: Raw dataset (`dataset.csv`)
- `notebooks/`: Exploratory analysis and linear regression model training (`analysis.ipynb`)
- `src/`: Streamlit dashboard for real-time sales forecasting (`app.py`)

## Tech Stack
- Python, Pandas, Matplotlib, Scikit-Learn, Streamlit
